# АвтоДеталь — интернет-магазин автозапчастей

Функциональная верстка интернет-магазина автозапчастей на **React + TypeScript + Vite**.
Адаптивная, с рабочим каталогом, фильтрами, корзиной и оформлением заказа.

## Стек

- **React 18** + **TypeScript**
- **Vite 6** — сборка и dev-сервер
- **React Router 6** — клиентская маршрутизация (HashRouter, работает на GitHub Pages)
- Глобальный CSS (mobile-first, методология БЭМ), без UI-библиотек

## Запуск

```bash
npm install      # установка зависимостей
npm run dev      # dev-сервер с hot-reload → http://localhost:5173
npm run build    # production-сборка в папку dist/
npm run preview  # локальный просмотр собранной версии
```

## Структура

```
src/
├── main.tsx              # точка входа, провайдеры (Router, Cart)
├── App.tsx               # маршруты + общий каркас (Header/Footer)
├── index.css             # все стили (адаптив, БЭМ, CSS-переменные)
├── components/
│   ├── Header.tsx        # шапка, поиск, мобильное меню, счётчик корзины
│   ├── Footer.tsx
│   └── ProductCard.tsx   # карточка товара (переиспользуемая)
├── context/
│   └── CartContext.tsx   # состояние корзины (useReducer + localStorage)
├── data/
│   └── products.ts       # каталог товаров и типы (Product)
└── pages/
    ├── Home.tsx          # главная
    ├── Catalog.tsx       # каталог: фильтры, поиск, сортировка
    ├── Product.tsx       # карточка товара, галерея, выбор количества
    ├── Cart.tsx          # корзина: изменение количества, удаление, итоги
    ├── Checkout.tsx      # оформление заказа
    ├── Contacts.tsx      # контакты + форма обратной связи
    └── NotFound.tsx      # 404
```

## Что работает (функционал)

- **Каталог** — фильтрация по производителю, цене и наличию; сортировка по цене; поиск по названию/артикулу/бренду через строку поиска в шапке.
- **Корзина** — добавление товаров, изменение количества, удаление, подсчёт суммы и доставки. Состояние **сохраняется в localStorage** (не теряется при перезагрузке).
- **Оформление заказа** — форма с валидацией обязательных полей, выбор доставки и оплаты, экран подтверждения.
- **Маршрутизация** — отдельные страницы, хлебные крошки, прокрутка вверх при переходе.

## Где менять данные

Все товары и категории — в одном файле [`src/data/products.ts`](src/data/products.ts).
Цвета и отступы темы — в `:root` файла [`src/index.css`](src/index.css).
Картинки-заглушки — в `public/img/` (заменить на реальные фото товаров).

## Деплой

В проекте настроены два способа:

1. **GitHub Pages (автоматически)** — push в ветку `main` запускает GitHub Action
   (`.github/workflows/deploy.yml`), который собирает и публикует сайт.
   Нужно один раз включить Pages: *Settings → Pages → Source: GitHub Actions*.

2. **Вручную через gh-pages**:
   ```bash
   npm run deploy
   ```

`base: './'` в `vite.config.ts` делает сборку переносимой — её можно открыть
на GitHub Pages, Netlify, Vercel или любом статическом хостинге.

## Дальнейшая интеграция

Сейчас данные статические (моки в `products.ts`). Для боевого магазина:
- заменить моки на запросы к API/CMS (точки данных изолированы в `data/` и `context/`);
- подключить реальную оплату и отправку заказа на бэкенд из `Checkout.tsx`;
- добавить фото товаров в `public/img/`.
