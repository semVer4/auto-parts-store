# Визуальная система АвтоДеталь

Статус: направление согласовано пользователем; интерфейсы подготовлены к публикации на существующем Netlify-сайте. API и правила заказов сохранены.
Направление: редакционный автомобильный магазин, тёплая бумажная основа, графит, красный акцент.

## UI UX Pro Max

Источник: `nextlevelbuilder/ui-ux-pro-max-skill`, commit `56ea9cf174ed86786187daa9de0e6247cb0747e4`.
Первый запрос `automotive parts ecommerce editorial` предложил Motion-Driven и Syncopate/Space Mono.
Он отклонён: анимационная нагрузка и шрифты не подходят русскоязычному каталогу.
Уточнение `auto parts retail catalog` дало Minimalism & Swiss Style и торговую сетку.
Это основа решения; палитра и шрифты адаптированы осознанно, а не скопированы из ответа.

- Фон `#f4f2ec`, текст `#171919`, акцент `#c8231b`.
- Oswald/Golos Text: локальные Google Fonts, лицензии OFL рядом с файлами.
- Нет emoji-иконок на главной, автоматических каруселей, параллакса или декоративного blur.
- Поиск, корзина, API и валидация сохраняются. Демо явно обозначено; вымышленных бизнес-метрик нет.
- Проверка: адаптивность, keyboard/focus, reduced motion, функциональные E2E.

Точечный UX-запрос `heading text overflow wrap` подтвердил правило: не скрывать
переполнение, а проверять, что контент помещается. React-запросы для переноса
текста и responsive layout не дали совпадений; исправление fallback-шрифта и
grid основано на стандартном CSS и фактических браузерных проверках, не на
несуществующей рекомендации из базы.

Фотографии — иллюстративные AI-generated assets встроенного image_gen.
Фильтр не является фотографией точного SKU. PNG-оригиналы сохранены в `design-assets/source/`, WebP для сайта перекодированы
существующим Sharp без изменения размеров или композиции.

## Применение к страницам

- Главная: крупная редакционная типографика, естественная автомобильная фотография, поисковый сценарий и навигация по реальным категориям.
- Каталог и товар: единый предметный фотостиль, читаемые фильтры, метаданные, характеристики и покупка; без вымышленной популярности.
- Корзина, оформление и заказы: пронумерованный пользовательский путь, ясные суммы, статусы, состояния ошибок и пустых списков.
- О проекте, помощь и 404: та же сетка и типографическая иерархия; технические пояснения остаются доступны без верхнего рекламного баннера.
- По просьбе пользователя верхняя плашка DEMO удалена. Предупреждение о тестовых данных и отсутствии реальных платежей сохранено в оформлении и справочной информации.
- Главная, каталог и общий подвал используют нейтральные тексты без упоминаний демо/портфолио, включая доступные названия ссылок и meta description. Ограничения проекта по-прежнему описаны на странице оформления, в справке и документации; реальные платежи и поставки не заявляются.
- Остальные публичные страницы, подтверждение заказа и сообщения ошибок тоже используют обычные пользовательские формулировки без «демо-сессии», «ненастоящей админки» и технической презентации. Перед вводом контактов остаётся одна короткая информация: оплата и доставка через сайт не выполняются, для ознакомления нужны вымышленные контакты. Ограничения оплаты и отправки также доступны в справке; README и архитектурная документация остаются фактическими.

Каталог остаётся демонстрационным; изображения деталей иллюстративные, не фотографии точных артикулов. Новые продуктовые изображения не подтверждают техническую совместимость.

Промпты и пути изображений: [DESIGN-ASSETS.md](DESIGN-ASSETS.md).
