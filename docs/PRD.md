# Продукт: демонстрационный заказ автозапчастей

## Цель

Показать не только сгенерированный интерфейс, но и законченный проверяемый сценарий: каталог → корзина → серверная валидация → сохранение заказа → повторное чтение → изменение статуса.

Пользователь — посетитель портфолио. Все товары, заказы, контакты и статусы используются только для демонстрации.

## В рамках проекта

- Поиск, фильтры, сортировка и карточки существующего каталога.
- Корзина с количеством, удалением и сохранением между перезагрузками.
- Контакты, выбор доставки, понятные сообщения об ошибках.
- Серверная проверка товара, количества, наличия, контактов и адреса.
- Серверные цены и расчёт доставки: самовывоз — 0 ₽, курьер — 350 ₽, транспортная компания — 450 ₽.
- Сохранение заказа в Netlify Blobs с доступом только из своей демо-сессии.
- Повторная отправка с тем же requestId и данными возвращает существующий заказ; изменённый запрос с тем же ключом отклоняется. Условная запись единого агрегата сессии защищает от конфликтующих параллельных обновлений.
- История заказов после reload; допустимые изменения демонстрационных статусов с проверкой версии.
- Автотесты API/бизнес-логики и сквозные браузерные проверки.

## Критерии приёмки

1. Доступный товар можно заказать; сумма в ответе API рассчитана на сервере.
2. Некорректный запрос не создаёт заказ, а UI оставляет корзину и позволяет исправить данные.
3. Успешный ответ содержит сохранённый номер заказа, сумму и статус, без обещания реального письма или доставки.
4. Сохранённый заказ виден после перезагрузки в том же браузере.
5. Второй браузер не получает чужие заказы; чужой ID не позволяет прочитать или изменить запись.
6. Повтор одного запроса не создаёт дубль; конкурентные изменения защищены условной записью. При исчерпании повторов сервер возвращает конфликт, а не неподтверждённый успех.
7. `new → confirmed → shipped` и отмена из `new`/`confirmed` записываются в историю. Терминальные статусы неизменяемы; устаревшая версия возвращает конфликт.
8. `npm run check` и `npm run test:e2e` завершаются успешно.

## Вне рамок

Реальные платежи, email/SMS/Telegram-рассылка, доставка, CRM, склад, администрирование всех заказов, аккаунты покупателей и промышленная эксплуатация. Не заявляем бизнес-эффект, аудит безопасности и нагрузочную устойчивость, которые не измерялись.
