# Работа с АвтоДеталь

- Сначала прочитайте `README.md` и `docs/ARCHITECTURE.md`. Это demo, не действующий магазин.
- Не добавляйте вымышленные отзывы, бизнес-метрики, отправку писем или утверждения об оплате.
- Не отправляйте реальные персональные данные и секреты в репозиторий, логи и тесты.
- Сохраняйте доступные названия полей/кнопок и адаптивность. Используйте существующие React/TypeScript-компоненты и CSS-паттерны.
- Сервер рассчитывает цены и доставку; клиент не является источником истины. Не обходите проверку сессии, валидацию и допустимые переходы статусов.
- Ошибка API не должна очищать корзину. Повторная отправка того же заказа использует тот же requestId.
- Не меняйте чужие изменения вне задачи; просматривайте diff перед завершением.
- После изменения логики запускайте `npm run check`; для пользовательского сценария также `npm run test:e2e`.
- Если команды не запускались или не прошли, сообщите это прямо. Не утверждайте deploy без проверки опубликованного сайта.
- Подключение внешних сервисов, изменение расходов и публикация требуют отдельного согласованного шага.
